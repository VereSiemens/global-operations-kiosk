Which visualisation do you prefer?

Option 1: Focus on Dynamics

Dark background (very dark blue) with subtle glowing continent outlines. Animated dots represent customer locations. Colors indicate status: Siemens blue (active, 09:00-17:00), light blue/gray (closed), yellow (national holiday), red (critical). Privacy toggle: public mode hides client names; internal mode shows customer names, city, local time, and additional details.

Option 2: Focus on Information

Dark blue background with detailed map (borders, cities, water) in muted colors. Dots represent locations with hover-activated info bubbles showing local time, status, temperature, and other information. Privacy toggle: public mode shows only basic info; internal mode displays client names, contacts, open tickets, and system status.

Option 3: Focus on Context

Large central map with side panels and ticker-tape at the bottom. Left panel shows priority list of locations needing attention (critical status, near closing time, open tickets). Right panel displays global statistics (active locations, holidays today, critical alerts, response time) and upcoming events. Map auto-zooms on important events. Ticker-tape shows live updates like holidays, shift changes, and alerts. Privacy toggle: public mode hides client names and sensitive data; internal mode shows detailed information and specific alerts.

Option 4: Focus on Immersion

3D rotating globe with detailed world map. Markers are glowing spheres or pyramids with colors indicating status (green: open and good, orange: open but near closing, blue: closed, yellow: holiday, red: critical). Marker height indicates urgency. Real-time day/night effect shows which side of Earth is in sunlight. Interactive rotation allows manual control with mouse. Info popups appear on hover showing client name, local time, status, and alerts. Ticker-tape displays live updates. Privacy toggle: public mode hides client names; internal mode shows detailed information.
